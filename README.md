# IGNITE 2026

Landing site for **IGNITE**, the 4-week industry product prototyping sprint hosted by Vijaya Vittala Institute of Technology (VVIT), Bengaluru, with SmartX Technologies and AptPath.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion
- sharp (asset/image pipeline)
- Deploy target: Vercel (SPA)

## Local development

```bash
npm install
npm run dev        # start dev server
npm run generate:assets  # regenerate favicon / apple-touch-icon / og-image from the logo
npm run brochure     # build + render the printable 6-page DL booklet
npm run build      # type-check + production build
npm run preview    # preview the production build locally
```

## Brochure (printable PDF)

`npm run brochure` builds a self-contained **6-page DL booklet** and renders it to PDF for printing or sharing. Every page is **99 × 210 mm (DL), portrait** — six independent pages, so the PDF can be printed six-up or imposed three-up, two pages per side of A4 portrait, folded and saddle-stitched into a booklet.

The source of truth is the template `brochure/hack-matrix-brochure.html` — it is hand-authored and its copy is hardcoded, deliberately decoupled from the React config in `src/data/eventConfig.ts`, so the two do **not** stay in sync.

### Pages

| # | Page | Contents |
|---|------|----------|
| 1 | Cover | VVIT seal (only logo placement in the booklet), title, date, key-stat meters, register CTA |
| 2 | Overview | Statement page, pull-quote block, at-a-glance readout |
| 3 | Themes | The nine theme tracks as a 3 × 3 angular card grid |
| 4 | Eligibility | Two-column split: eligible disciplines vs. what to bring / what we provide |
| 5 | Prizes | Prizes TBA block, judging criteria as horizontal weight bars |
| 6 | Back | Merged run-of-show (register → results), ground rules, QR code, contact + partners |

### Design system

Dark technical-blueprint. All tokens are CSS custom properties in the `:root` block of the template.

- Surfaces `#05070A` / `#0A0E14` / `#0F141C`; hairlines `#1B2430` / `#2A3646` / `#3A4859`
- Text `#DCE3ED` / `#A8B3C2` / `#7C8798` / `#4A5464`
- Accents `#22D3EE` cyan (primary signal), `#7C6CFF` violet (secondary), `#2E9E5B` VVIT seal green, `#F5C451` amber — **amber is reserved exclusively for the TBA prize block** so it keeps its meaning
- Motifs: hairline blueprint grid, four corner brackets per page (`.reticle`/`.bracket`), page numeral in a reserved right-hand lane (`.ghostnum`, interior pages carry `padding-right: 27mm` so the watermark never crosses body copy), `// NNN · Section` micro-labels (`.stamp`), cut-corner blocks via `clip-path` (no `border-radius` on content), progress meters (`.bar-track`/`.bar-fill`), bracketed chips `[ AI ]` (`.tag`), glyph bullets `▸` (`.tick-list`)
- Per-page layout systems (each page has a deliberately different composition, so no skeleton repeats): `.quote` pull-quote, `.grid3`/`.tcard` theme cards, `.split` two-column, `.wrow`/`.wt` judging weight bars, `.sched`/`.sched-item` run-of-show time gutter
- Type: Space Grotesk (display), Inter (body), JetBrains Mono (labels/numerals)

Re-run `npm run brochure` after any palette or layout change — `tool/render-brochure.mjs` fails the build on palette drift, missing HUD furniture, non-1px hairlines, circular-bullet regression, geometry drift, overflow, clipped text, or a logo appearing more than once.

### Printing

- 7 pages of **99 × 210 mm portrait**. For two-up on A4 portrait, print at 200% or use the PDF at 99 × 210 mm per page.
- If Playwright is unavailable, open `dist/brochure/hack-matrix-brochure.html` and use Print → Save as PDF with **Paper size: custom 99 × 210 mm**, **Margins: None**, **Background graphics: ON**.

### Build

```bash
npm run brochure            # generate:brochure + brochure:render
npm run generate:brochure   # template -> dist/brochure/hack-matrix-brochure.html (logo + QR inlined)
npm run brochure:render     # dist/brochure/*.html -> .pdf + preview/page-*.png
```

- Outputs: `dist/brochure/hack-matrix-brochure.html` (self-contained, logo and QR inlined as base64 data URIs), `dist/brochure/hack-matrix-brochure.pdf` (7 portrait pages), and one PNG preview per page — `dist/brochure/preview/page-1.png` … `page-6.png`.
- Assets: the logo is `public/vvitlogo.jpg` and is inlined **once only**, on page 1; the QR is `brochure/hack-matrix-qr.svg`, generated by `tool/make-qr.py` (override the encoded URL with `BROCHURE_URL`), and appears once on page 6.
- To edit: change the template, then re-run `npm run brochure`. The `__LOGO_DATA_URI__` and `__QR_DATA_URI__` tokens are substituted at build time — never hand-edit anything in `dist/`.
- Override the logo with the `LOGO` env var (PowerShell): `set LOGO=public/otherlogo.png && npm run generate:brochure`.
- `brochure:render` falls back to the locally installed Chrome/Edge because the bundled Playwright Chromium is not installed; it exits non-zero on any real layout overflow or clipped text.
- Currently marked TBA: prizes (config `prizes.status === "TBA"`), registration open/close dates, sponsors (`sponsors.partners` is empty), and the phone number (`contact.phone` is still `+91 XXXXX XXXXX`, so it is deliberately omitted from the brochure). Fix those in `src/data/eventConfig.ts`, then update the template.

## Go-live checklist

1. **Fill in `src/data/eventConfig.ts`** — `registration.googleFormUrl`, `contact` (email / phone / socials), and `seo.siteUrl` (already set to the production URL `https://www.ignitearena.live`).
2. **Run `npm run generate:assets`** to regenerate OG/favicon assets from `public/vvitlogo.jpg` (logo source: copy of `vvitlogo.jpg`; override with `LOGO` env var).
3. **Deploy to Vercel** (framework preset "Vite" picks up `vercel.json` automatically).
4. **Optional** — drop partner logo PNGs into `/public` and reference them in `sponsors.partners` in the config.

> Note: `index.html` embeds SEO meta, canonical URLs, and JSON-LD structured data — these already point at `https://www.ignitearena.live`, but re-check them (and `seo.siteUrl`) if the domain ever changes.
